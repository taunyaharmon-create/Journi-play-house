# 👑 Journi’s Play House 💕

**Journi’s Play House** is a custom interactive mobile game created especially for Journi.

Built for a young toddler, the entire game follows one simple idea:

## 🎀 Listen → Look → Tap → Play → Love → Celebrate 💗

Journi never has to know how to read in order to play.

---

## 🏠 Explore Journi’s House

Journi can explore seven illustrated rooms:

- 👶 Nursery
- 🛁 Bathroom
- 🍓 Kitchen
- 🧸 Playroom
- 👨‍👩‍👧 Family Room
- 🌳 Backyard
- 🌙 Bedroom

Each room contains its own interactive activities, games, care routines, learning experiences, and surprises.

---

## 💗 Toddler-Safe Game Design

Journi’s Play House is intentionally designed without traditional failure mechanics.

There are:

- No lives
- No countdown timers
- No game-over screens
- No flashing Xs
- No lost points
- No harsh error sounds
- No reading required to play

When Journi makes a different choice, the game gently encourages her to try again.

Correct items snap gently into place.

Incorrect items return smoothly to their starting positions.

Large touch targets, forgiving interaction areas, visual cues, family photographs, character artwork, and Boo-Boo’s recorded voice guide Journi through the game.

---

## 🎙️ Boo-Boo’s Voice

Game narration and encouragement use **Boo-Boo’s real recorded audio**.

The game does not substitute browser, computer, or iPhone text-to-speech when a recording is unavailable.

If Boo-Boo does not have a recording for something, the game simply stays silent.

Only one Boo-Boo recording plays at a time so instructions do not overlap.

Settings and reset controls are separated from Journi’s normal toddler gameplay.

# 📱 MOBILE-FIRST DESIGN

Journi’s Play House is designed primarily as a mobile web game with special attention to iPhone touch interaction.

Gameplay uses pointer-based controls for:

- 👆🏽 Tapping
- 🤏🏽 Dragging
- ↔️ Swiping
- ✌🏽 Multi-Touch Interaction

Touch targets are intentionally large and forgiving.

# 🎯 GLOBAL TODDLER RULES

### 0% Text Blockades

Gameplay never depends on Journi being able to read.

### No Punishment

There are no lost points, lives, harsh buzzers, game-over screens, or failure penalties.

### Boo-Boo Voice Only

Spoken guidance uses Boo-Boo’s recorded voice.

No browser or device text-to-speech substitutes for missing recordings.

### Persistent Memories

Love Hearts, Baby Love Meters, rewards, purchases, and scrapbook memories are remembered locally.

### Toddler-Safe Navigation

Large visual controls and simple navigation keep Journi inside an easy-to-understand play environment.
