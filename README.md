# 👑 Journi's Play House: Core Engine Profile 💕

Welcome to the internal asset workspace for **Journi's House**, a premium toddler-focused mobile web application built with custom HTML, CSS, and JavaScript.

## 🎯 Global Toddler Rules Architecture

- **0% Text Blockades:** Gameplay never depends on Journi being able to read. Large visual controls, character artwork, intuitive interactions, and Boo-Boo's recorded narration guide play.
- **No Punishment Vectors:** Correct items snap gently into place. Incorrect placements float smoothly back to their starting position with no lost points, harsh buzzers, flashing Xs, timers, lives, or game-over screens.
- **Boo-Boo Voice Only:** Spoken game guidance uses Boo-Boo's recorded audio. Missing audio remains silent rather than substituting browser or device text-to-speech.
- **Persistent Memory Tracking:** Love Hearts, Baby Love Meters, unlocked rewards, scrapbook memories, and other progress are stored locally so Journi can return to her house without starting over.
- **Toddler-Safe Navigation:** Large visual touch targets, a permanent Home control, simple room-to-room navigation, and forgiving interactions are used throughout the game.

## 🏠 Main Game Flow

**Front Door → House / Room Selection → Activity → Love & Care Rewards → Treasure Shop → Camera → Family Scrapbook**

## 💗 Reward Systems

- **Love Hearts** are spendable Treasure Shop currency.
- **Baby Love Meters** track permanent care and affection for Ella, Emma, and Jheneá.
- Love Meter progress never decreases.
- Activities have no failure punishment.
- Rewards celebrate participation, care, learning, and exploration.
